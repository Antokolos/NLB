# NLB — Non-Linear Book (Java): редактор NLBB, библиотека NLBL, веб-плеер NLBW

Отвечать и писать комментарии, сообщения коммитов и документацию — на русском языке.

## Модули (Maven, Java 21; корневой `pom.xml`, версия 1.0.5-SNAPSHOT)
- **NLBL** — библиотека: модель книги (`com.nlbhub.nlb.api`, `domain`: `NonLinearBookImpl`,
  `PageImpl`, `ObjImpl`, `LinkImpl`, `ModificationImpl`, `VariableImpl`, `MediaFileImpl`),
  чтение/запись каталога книги, выражения через ScriptEngine (Rhino/Nashorn), экспортёры
  (`domain/export`: `ExportManager`, `STEADExportManager`, `VNSTEADExportManager`, QSP, URQ,
  ChoiceScript, ASM, текст, HTML/PDF…).
- **NLBB** — редактор (Swing, piccolo2d, swingx). Встраивает веб-плеер NLBW: `MainFrame` кладёт
  книгу в кэш `Launcher.putNLBInMemoryToCache` и открывает её в браузере.
- **NLBW** — веб-плеер на Jetty (ee10) + Jersey: `Launcher` (сервер, сервлет на `/nlb/*`),
  `service/rest/GetNLBDataService` (REST: `/{bookId}/start`, `/{bookId}/page/{toPageId}`,
  `/{bookId}/link/{fromPageId}/{linkId}`), страницы — XML + XSL (`xsl/page.xsl`,
  `xsl/history.xsl`). Здесь же лежат ресурсы экспорта в INSTEAD: `res/vnstead/modules/nlb.lua`,
  `vn.lua`, `paginator.lua`, `gobj.lua`…, и настройки экспорта `cfg/config.xml`.

Сборка: `mvn -q -DskipTests package` (из корня). Тесты — `mvn test`.

## Главная задача: полноценный веб-плеер на Java (NLBW)
Текущий веб-плеер — отладочный инструмент редактора: навигация через `History`/`DecisionPoint`
и `NonLinearBookImpl.createFilteredPage`, один общий `static` журнал на всех (`s_history`),
вывод — XML + XSL. Нужно довести его до плеера, который играет книги так же полно, как
экспорт в INSTEAD: **все виды модификаций, внутренние и внешние модули (подмодули),
автопереходы (autowired), объекты и инвентарь (взять/применить/контейнеры), теги, таймеры
страниц, достижения, сохранения, темы VN и STANDARD, картинки/анимация/звук/музыка, языки
книги**. Реализация — целиком на Java, без Emscripten/WebAssembly. Один в один с C++-плеером
быть не обязано, но поддержка всех возможностей книги — обязательна.

Сначала — аудит: что из этого уже есть в NLBW/NLBL, что частично, чего нет. План — этапами
с критериями приёмки; большие этапы — отдельными коммитами/PR.

### Что считать правильным поведением (по убыванию)
1. **Экспорт в INSTEAD** — книги реально играли через него: `nlb.lua` (NLBW/res/vnstead/modules)
   + `ExportManager` (диспетчеризация модификаций) + `STEADExportManager` /
   `VNSTEADExportManager` (что и как генерируется). Это эталон семантики.
2. **NLBNavigator** (github.com/Antokolos/NLBNavigator, ветка `main`) — C++-плеер, в котором эта
   семантика уже реализована, проверена и сверена с INSTEAD. Это **исполняемая спецификация**:
   при вопросе «как должно работать» смотреть там:
   - `Source/NLBReader/.../PlayerEngine.{h,cpp}` — навигация, автопереходы, модули, события;
   - `PlayerContext` — состояние (переменные, списки, контейнеры, теги, достижения, снимки);
   - `ModificationInterpreter` — все виды модификаций, выражения, картинки/звук с условиями;
   - `Source/NLBPresentation/.../Session`, `GameScreen`, `ScreenModel` — модель экрана VN/
     STANDARD, порции текста, экран вариантов, инвентарь, меню, сохранения, озвучка;
   - `docs/*.md` — описания решений.
3. Встроенный старый веб-плеер NLBW — **не** эталон (базовый и неполный).

### Осознанные решения NLBNavigator (сохранить и в Java)
- GOTO в модификациях ссылки важнее цели ссылки; страница, которую сразу покидают по
  автоссылке, всё равно показывает свой текст; игра окончена, только когда ходов не осталось.
- Таймер страницы тикает раз в ход.
- Достижения сохраняются между прохождениями (как в INSTEAD).
- Порции текста VN — как `VNSTEADExportManager.getPreprocessedChunks`: строка текста — порция;
  длинная — по предложениям (порция > 100 символов, хвост до 330 — к последней); листание
  никогда не повторяет прочитанное.
- Озвучка по фразам: SFX-звуки страницы через `;` — по одному на порцию, **в порядке поля**
  (в `nlb.lua` очередь — стек, фразы шли с конца; это ошибка, не повторять). Флаг SFX у файла —
  файл `.flag` рядом с ним.
- Пресеты медиа `.preset` (DEFAULT/COMPRESSED/NOCHANGE), условия `.constrid`, переадресации
  `.redirect` — привязаны к имени файла.
- Тексты по умолчанию (game-inv, game-nouse) и needs-action-count — из настроек экспорта
  (`cfg/config.xml`, раздел `<export>`).

### Пожелания к устройству
- Ядро плеера — без веба (например, пакет `com.nlbhub.nlb.player` в NLBL): состояние сессии,
  ход, модель экрана. NLBW — тонкий слой: REST (JSON) + клиент на HTML/CSS/JS, который рисует
  модель экрана (VN и STANDARD).
- Состояние — на сессию игрока, не `static`; несколько игроков одновременно.
- Сохранения — сериализуемый снимок состояния (JSON).
- Медиа — отдача файлов книги по HTTP; формат пакета `.nlbpack` описан в NLBNavigator
  (`Source/NLBCore/.../util/BookPack.cpp`, `docs/pack.md`) — поддержать чтение.
- Тесты: JUnit на модификации и навигацию; приёмка — сравнение журнала прохождения с C++
  (`nlb_main`/`nlb_sdl --log` в NLBNavigator пишут текст страниц, объекты, инвентарь и выбор).

## Правила
- Не ломать редактор NLBB и экспорт: веб-плеер развивается рядом.
- Модель книги и формат каталога книги менять только с совместимостью со старыми книгами.
- Тестовые книги (каталоги) — у владельца; если нужна книга для проверки — попросить.
