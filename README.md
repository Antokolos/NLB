NLB
===

Non-Linear Book: редактор нелинейных книг (NLBB), библиотека модели книги и экспорта (NLBL) и
веб-плеер (NLBW). Сборка — `mvn -q -DskipTests package`, дистрибутив со встроенной Java —
`build.sh` / `build.bat` (каталог `dist`).

Документация:
- `docs/web-player.md` — веб-плеер: устройство, раскладки VN и STANDARD, темы;
- `docs/external-modules.md` — внешние модули книги и git (подмодули).

## Большие книги и антивирус

Книга NLB — каталог из многих мелких файлов (у «Фронтира» — около 27 тысяч). На Windows
антивирус (Microsoft Defender и другие) проверяет каждый файл при открытии и записи, и на
большой книге это минуты: первое открытие «Фронтира» — около двух минут вместо 25 секунд с
исключением.

Поэтому:
- добавьте каталог с книгами в исключения антивируса (Defender: «Безопасность Windows» ->
  «Защита от вирусов и угроз» -> «Параметры» -> «Исключения» -> «Добавить исключение» ->
  «Папка»);
- редактор и веб-плеер держат кэш книги одним файлом (`%LOCALAPPDATA%\NLB\cache`): повторное
  открытие не открывает файлы книги, а только перечисляет её каталоги; файлы, изменённые
  снаружи (правка, `git pull`), читаются заново. Кэш выключается ключом
  `-Dnlb.bookCache=false`;
- при сохранении на диск пишутся только изменившиеся файлы.
