# Тема INSTEAD «default»

Стандартная тема INSTEAD (https://github.com/instead-hub/instead, каталог `themes/default`,
коммит 1a07e0f), лицензия — `COPYING` (MIT, © Peter Kosyh).

Веб-плеер NLBW берёт её базовой темой, как INSTEAD и NLBNavigator (`--base-theme`): в ней заданы
параметры по умолчанию (звук щелчка, курсор, шрифты, цвета…), а тема игры NLB
(`res/vnstead/themes/default`) переопределяет часть из них. Обе зашиваются в jar NLBW
(`com/nlbhub/nlb/web/player/theme/base` и `…/game`).
